# MechE_Math_Assignment6
Assignment 6 of Mech E Math, intro to PDEs (masses on a vibrating string)

- `string_simulation` - basic animation of the string driven at its 2nd resonant frequency
- `run_resonance_search` - modal frequencies for n = 2 and n = 3 and a frequency sweep of the simulation to check them
- `run_mode_shape_animation` - mode shape videos for modes 1-3 (5 masses), simulation from rest on top and the predicted mode shape from the eigenvector on the bottom. `run_mode_shape_animation(2)` just makes the mode 2 one

Videos and figures save one folder up in `Assignment 6 Report Figures` so they stay out of the repo.
